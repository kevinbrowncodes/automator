# automator

Everything macOS Automator on my Mac: Quick Actions, standalone workflows,
Automator applications, and the shell scripts they call.

## Layout

| Folder | What lives here | Where macOS expects it |
|---|---|---|
| `quick-actions/` | `.workflow` bundles that appear in Finder's Quick Actions / Services menu | `~/Library/Services/` |
| `workflows/` | Standalone `.workflow` files you open and run from Automator | anywhere |
| `applications/` | Automator `.app` bundles (double-click or drop files on them) | anywhere |
| `folder-actions/` | Folder Action workflows (none yet) | `~/Library/Workflows/Applications/Folder Actions/` |
| `scripts/` | Shell scripts referenced by the above | anywhere |

Automator documents are bundles: a `.workflow` or `.app` is a folder, and the
real content is `Contents/document.wflow` (an XML plist). That file is what
`git diff` shows you. The `QuickLook/` PNGs inside bundles are regenerated by
Automator on every save, so expect them to churn.

## Day to day

**Install the Quick Actions on a new Mac**

```sh
./install.sh
```

Copies everything in `quick-actions/` into `~/Library/Services/` and refreshes
the Services menu.

**After editing a Quick Action in Automator**

Automator saves Quick Actions straight to `~/Library/Services/`, not to this
repo. Pull the change back, then commit:

```sh
./pull.sh          # refresh the ones tracked here
./pull.sh --all    # also grab any new ones on this Mac
git diff           # sanity-check
```

**Workflows and apps** are not installed anywhere. Open them from this repo
directly, or edit them in Automator and save back into the same folder.

## Inventory

### Quick Actions

- **Claude - ask**, **Claude - codeHere**, **Claude - send**: installed by the
  Claude desktop app. Selected text, folder, or files go to Claude via the
  `claude://` URL scheme.
- **Crop to Square**: center-crops the selected images to a 1:1 square and writes
  `<name>-square.<ext>` next to each original. Originals are untouched. Built on
  the `sips` tool that ships with macOS, so there is nothing to install.
- **Extract Last Frame**: saves the last frame of a movie as `<name>_lastframe.png`
  next to it. Needs Homebrew `ffmpeg`.
- **New Text Document**: creates `New Text Document.txt` in the front Finder window.
- **Open in Visual Studio Code**: opens the selection in a new VS Code window.

### Workflows

- **Combine Excel Workbooks**: starts from `~/Desktop/INBOX`.
- **Create New File**: prompts for a filename and touches it in the front Finder window.
- **Minmize All Windows**: hides every app except Finder and collapses Finder windows.
- **Text > Wrap in Quotes**: wraps the input text in double quotes.

### Applications

- **new app / board / chat / code / devonthink / file / NLM / note / path / web**:
  one-click launchers. `new chat` shows a picker for the AI chat apps;
  `new file` asks which Finder window gets a new `Untitled.txt`.
- **AudioLDM Transfer**: drop audio files on it to regenerate them with AudioLDM.
  Calls `scripts/audioldm_transfer.sh`.
- **AutomateCamp1**: runs the published AutomateCamp .NET build.
- **Create Blank Text File**: makes a new file in the front Finder window.
- **Move**: Move Finder Items with no destination set.

## Things that are pinned to this Mac

These reference paths outside the repo and will need editing on another machine:

- `AudioLDM Transfer.app` calls the script at its **old iCloud location**
  (`~/Library/Mobile Documents/com~apple~Automator/Documents/Scripts/`), not
  the copy in `scripts/`. The script itself activates a venv at `~/venvs/audiosr`.
- `AutomateCamp1.app` runs a binary on the external volume `Macintosh ED`.
- `Extract Last Frame` hardcodes `/opt/homebrew/bin/ffmpeg`.

## Things git cannot carry

- Custom Finder icons on `.app` bundles live in a resource fork on an `Icon\r`
  marker file. Git ignores it, so re-apply custom icons by hand after a fresh clone.

## Source of truth

The originals still exist in `~/Library/Services/` and in iCloud Drive under
`Automator/`. Nothing there was moved or deleted. Going forward, this repo is
the copy to trust.
